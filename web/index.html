Mihomo 配置生成器

项目仓库：github.com/Nimbly8836/generate_mihomo_config。更多说明请参考仓库。

直接填写参数，或编辑完整 values.yaml，生成后下载 config.yaml。两种输入模式独立，不会互相转换。

基础设置

仅影响表单模式。需要支持 dialer-ip4p-convert 的 Mihomo 核心；不会自动开启 IPv6 或修改 WG 节点。YAML 模式请使用 config_overrides 配置。

订阅

代理节点订阅，不是分流规则集。每行：名称 | URL | 前缀；前缀可省略。

WireGuard 内网节点

点击添加后填写节点参数。每条配置自动生成 wg_名称 分组和内网规则，不加入普通代理出口；手写规则仍优先。移除卡片可取消该节点。密钥不会写入浏览器本地存储，但会包含在下载的配置中。

自定义规则

下方填写手写匹配条件，每行一条，例如 DOMAIN-SUFFIX,example.com 或 IP-CIDR,192.168.10.0/24。只写“类型,匹配值”，不要附加目标组、no-resolve 等选项。完整或逻辑规则请在 YAML 模式使用 local_rules。

这里不能直接粘贴外部规则 URL。若要把一个外部列表全部交给 proxy，请在下面“外部规则集”中填写 URL，并将目标组设为 proxy。

每行：组名: 类型,匹配值。simple 模式使用 chat、ai 等父组；telegram、openai 等详细组只在 detailed 模式可用。

隐藏自动测速组与特殊目标

DIRECT、REJECT 是内置动作，也可以作为规则目标。一般优先选择可见的手动分组。

外部规则集

适用于 Clash/Mihomo 规则集的直链（如 GitHub raw 地址），不是节点订阅或网页链接。为每个来源填写名称、URL、内容类型、文件格式和目标组，自动生成 rule-providers 及 RULE-SET 规则。默认通过 DIRECT 下载、每 24 小时更新；由 Mihomo 使用配置时下载，本页面不会访问该 URL。

  • domain：纯域名列表；ipcidr：IP 网段列表；classical：带规则类型的列表，例如 DOMAIN-SUFFIX,example.com（不要带目标组）。
  • yaml：带 payload 的规则文件；text：逐行文本；mrs：二进制规则集，仅支持 domain / ipcidr。
  • 例如：custom_media | https://example.com/media.mrs | domain | mrs | media。若希望全部走普通代理，将目标组改为 proxy。
  • 匹配优先级：手写规则 → WG 内网规则 → 默认 SSH 直连 → 外部规则集 → 默认服务规则。
